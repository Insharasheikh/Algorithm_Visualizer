# Algorithm Visualizer 

A Java-based application that visually demonstrates how different algorithms work step-by-step, making complex concepts easier to understand.

**Tech:** Java, JavaFX

**Features:**

* Visualization of **Sorting Algorithms** (Bubble, Merge, Quick, etc.)
* Visualization of **Searching Algorithms**
* Visualization of basic **Graph Algorithms**
* Step-by-step execution
* Controls: **Play, Pause, Resume, Restart**
* Adjustable speed control for better understanding
* Interactive graphical interface

**Purpose:**
To simplify the understanding of algorithms by converting theoretical concepts into visual learning.
